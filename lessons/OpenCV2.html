1. Бинарное изображение и маска

Бинарное изображение — картинка, где у каждого пикселя только два возможных значения. В OpenCV это 0 (чёрный, «не подходит») и 255 (белый, «подходит»), тип uint8, shape (H, W). Маска — бинарное изображение, которое говорит, какие пиксели нас интересуют. Бинаризация — превращение обычной картинки в бинарную по какому-то правилу.

В уроке 1 правило было «цвет попал в диапазон HSV» (inRange). Теперь правило будет про яркость: «пиксель светлее порога». Фрагмент ЧБ-матрицы и его маска для правила «больше 100»:

3090150
200100101
2018060
→
00255
2550255
02550

Обратите внимание: 100 не прошло, 101 прошло. Правило «строго больше» важно, к нему мы вернёмся. Маска применяется к цветной картинке как в уроке 1: cv2.bitwise_and(img, img, mask=mask).

2. Пороговая фильтрация (thresholding)

Порог (threshold) — число T. Каждый пиксель сравнивается с T, и по результату сравнения ему назначается новое значение. Порог применяется к одноканальному (ЧБ) изображению.
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
ret, dst = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
#                         ^src  ^T   ^maxval ^тип

Функция возвращает два значения: ret (использованный порог) и dst (результат). Если написать dst = cv2.threshold(...), в dst окажется кортеж, и imshow выдаст ошибку.

Строго больше. OpenCV сравнивает «пиксель > T». Пиксель, равный порогу, в «прошедшие» не попадает: при T = 127 значение 127 даёт 0, а 128 даёт 255.

Пять типов порога

ТипЕсли пиксель > TИначе
THRESH_BINARYmaxval (255)0
THRESH_BINARY_INV0maxval (255)
THRESH_TRUNCTбез изменений
THRESH_TOZEROбез изменений0
THRESH_TOZERO_INV0без изменений

Первые два дают настоящую бинарную картинку. TRUNC и TOZERO сохраняют часть исходных яркостей: TRUNC «срезает» всё светлое до T, TOZERO обнуляет всё тёмное.

4. Гистограмма: как выбрать порог

Гистограмма яркости — график, на котором по оси X откладывается яркость (0–255), а по оси Y число пикселей с такой яркостью. Она показывает, из каких «групп» яркости состоит картинка.

Если картинка состоит из тёмного фона и светлого предмета, на гистограмме видны два «горба», и порог разумно ставить в «долину» между ними. Ниже гистограмма фотографии из демо выше: красная линия показывает текущий T, двигайте ползунок.

import matplotlib.pyplot as plt
plt.hist(gray.ravel(), bins=256, range=(0, 256))   # ravel() превращает матрицу в один ряд
plt.axvline(127, color="red")                        # линия порога
plt.show()

На практике порог часто подбирают на глаз по гистограмме и результату. Метод автоматического подбора (Оцу) вынесен в домашнее чтение (раздел 8).

5. Когда глобальный порог не работает: адаптивный порог

Глобальный порог — одно число T на всю картинку. Он хорош при ровном освещении. Если на листе лежит тень, тёмный «фон» в тени темнее светлого текста на свету, и ни одно T не разделит их правильно.

Адаптивный порог считает свой порог для каждого пикселя по его окрестности: T(x, y) = среднее по окрестности − C, и пиксель проходит, если он больше этого локального порога. blockSize — размер окрестности (нечётное число: 3, 5, 7, …, чтобы у окна был центр). C — константа, которую вычитают из среднего (чем больше C, тем строже, меньше «шума»).
dst = cv2.adaptiveThreshold(gray, 255,
        cv2.ADAPTIVE_THRESH_MEAN_C,      # или ADAPTIVE_THRESH_GAUSSIAN_C
        cv2.THRESH_BINARY, 31, 12)       # blockSize=31, C=12

MEAN_C берёт обычное среднее окна, GAUSSIAN_C — взвешенное, где центральные пиксели важнее. Результаты обычно похожи. Обратите внимание: в отличие от threshold, здесь нет параметра T и функция возвращает одно значение.

9. Типичные ошибки и шпаргалка

  • threshold возвращает два значения, не одно.
  • Пиксель, равный T, не проходит (сравнение строгое).
  • Порог применяется к ЧБ, а не к BGR.
  • blockSize адаптивного порога нечётный.

  • Маска это 0 и 255, а не 0 и 1.

01_threshold_matrix.py — 5 типов порога на матрице 5×5
"""Порог на маленькой матрице: сравните с ответом, который вы получили на бумаге."""
import cv2
import numpy as np

A = np.array([[  0,  60, 127, 128, 200],
              [255, 127, 128,  30,  90],
              [100, 250, 127, 129, 128],
              [ 10, 128, 180, 127,  64],
              [128, 127, 255,   0, 140]], dtype=np.uint8)

THRESH, MAXVAL = 127, 255     # пиксель БОЛЬШЕ порога (строго), равный порогу не проходит

types = {
    "BINARY":      cv2.THRESH_BINARY,       # > T -> maxval, иначе 0
    "BINARY_INV":  cv2.THRESH_BINARY_INV,   # > T -> 0, иначе maxval
    "TRUNC":       cv2.THRESH_TRUNC,        # > T -> T, иначе без изменений
    "TOZERO":      cv2.THRESH_TOZERO,       # > T -> без изменений, иначе 0
    "TOZERO_INV":  cv2.THRESH_TOZERO_INV,   # > T -> 0, иначе без изменений
}

print("Исходная матрица:\n", A, "\n")
results = {}
for name, t in types.items():
    ret, dst = cv2.threshold(A, THRESH, MAXVAL, t)   # возвращает ДВА значения
    results[name] = dst
    print(f"{name}  (порог={ret}):\n{dst}\n")

# Картинка: каждая матрица, увеличенная в 60 раз без сглаживания
def big(m):
    return cv2.resize(m, None, fx=60, fy=60, interpolation=cv2.INTER_NEAREST)

panels = [big(A)] + [big(m) for m in results.values()]
labels = ["original"] + list(results)
for p, lab in zip(panels, labels):
    cv2.putText(p, lab, (8, 24), cv2.FONT_HERSHEY_SIMPLEX, 0.7, 128, 2)
row1 = np.hstack(panels[:3]); row2 = np.hstack(panels[3:])
cv2.imshow("threshold types on 5x5 (any key to close)", np.vstack([row1, row2]))
cv2.waitKey(0)
cv2.destroyAllWindows()

03_threshold_slider.py — Ползунки порога и типа (окно OpenCV)
"""Интерактивный порог: двигайте ползунки. ESC или q - выход."""
from pathlib import Path
import cv2

img = cv2.imread(str(Path(__file__).parent / "images" / "cat.jpg"))
assert img is not None, "Не нашёл images/cat.jpg"
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

TYPES = [cv2.THRESH_BINARY, cv2.THRESH_BINARY_INV, cv2.THRESH_TRUNC,
         cv2.THRESH_TOZERO, cv2.THRESH_TOZERO_INV]
NAMES = ["BINARY", "BINARY_INV", "TRUNC", "TOZERO", "TOZERO_INV"]

WIN = "threshold"
cv2.namedWindow(WIN)
cv2.createTrackbar("T", WIN, 127, 255, lambda v: None)
cv2.createTrackbar("type", WIN, 0, 4, lambda v: None)

while True:
    t = cv2.getTrackbarPos("T", WIN)
    k = cv2.getTrackbarPos("type", WIN)
    _, dst = cv2.threshold(gray, t, 255, TYPES[k])
    view = dst.copy()
    cv2.putText(view, f"{NAMES[k]}  T={t}", (10, 30),
                cv2.FONT_HERSHEY_SIMPLEX, 0.9, 128, 2)
    cv2.imshow(WIN, view)
    key = cv2.waitKey(30) & 0xFF
    if key in (27, ord("q")):
        break
cv2.destroyAllWindows()

"""Метод Оцу «руками»: перебираем все пороги и ищем максимум межклассовой дисперсии.
Результат сравниваем с cv2.threshold(..., THRESH_OTSU)."""
from pathlib import Path
import cv2
import numpy as np
import matplotlib.pyplot as plt


def otsu_threshold(gray):
    """Возвращает (лучший порог, массив межклассовых дисперсий для T = 0..255)."""
    hist = np.bincount(gray.ravel(), minlength=256).astype(np.float64)
    p = hist / hist.sum()                       # доля пикселей каждой яркости
    levels = np.arange(256)

    sigma_b = np.zeros(256)
    for T in range(256):
        w0 = p[:T + 1].sum()                    # доля пикселей класса 0 (яркость <= T)
        w1 = 1.0 - w0                           # доля пикселей класса 1 (яркость > T)
        if w0 == 0 or w1 == 0:                  # один из классов пуст - порог бессмыслен
            continue
        mu0 = (levels[:T + 1] * p[:T + 1]).sum() / w0     # средняя яркость класса 0
        mu1 = (levels[T + 1:] * p[T + 1:]).sum() / w1     # средняя яркость класса 1
        sigma_b[T] = w0 * w1 * (mu0 - mu1) ** 2           # межклассовая дисперсия
    return int(np.argmax(sigma_b)), sigma_b      # argmax берёт первый максимум


# 1) Крошечный пример, который можно проверить на бумаге
tiny = np.array([[10, 10, 10, 20, 20, 200, 200, 210, 210, 210]], dtype=np.uint8)
T_mine, _ = otsu_threshold(tiny)
T_cv, _ = cv2.threshold(tiny, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print(f"tiny:     мой Оцу = {T_mine}, OpenCV = {T_cv:.0f}")

# 2) Реальные картинки
IMG = Path(__file__).parent.parent / "images"
fig, ax = plt.subplots(1, 3, figsize=(16, 4.5))
for a, name in zip(ax, ["even.png", "document.png", "noisy.png"]):
    gray = cv2.imread(str(IMG / name), cv2.IMREAD_GRAYSCALE)
    assert gray is not None, f"Нет {name}: запустите ../00_make_images.py"
    T_mine, sb = otsu_threshold(gray)
    T_cv, _ = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    print(f"{name}: мой Оцу = {T_mine}, OpenCV = {T_cv:.0f}")
    a.plot(sb); a.axvline(T_mine, color="red")
    a.set_title(f"{name}: межклассовая дисперсия\nмаксимум при T={T_mine}")
    a.set_xlabel("порог T")
