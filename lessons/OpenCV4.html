1. Что такое граница

Граница (edge) — место, где яркость изображения резко меняется: край предмета, переход от линии к полу, контур тени. Профиль яркости — значения пикселей вдоль одной строки (или любого отрезка), график «яркость от координаты».

Если пройти вдоль строки через край тёмного пола и светлого кубика, профиль будет похож на ступеньку: 20 20 20 20 100 100 100 100. Граница — там, где ступенька. Нам нужен способ автоматически находить, где значения меняются быстро. В математике скорость изменения функции — это производная. Значит, граница — это место, где модуль производной яркости большой.

2. Производная для пикселей: конечные разности

Производная определена для непрерывной функции: f'(x) = lim (f(x+h) − f(x)) / h при h → 0. У картинки пиксели идут с шагом 1, и h меньше 1 взять нельзя. Поэтому производную приближают разностями соседних пикселей. Чтобы понять, какое приближение лучше, выведем их из ряда Тейлора.

Вывод из ряда Тейлора

f(x + h) = f(x) + h·f'(x) + h²/2·f''(x) + h³/6·f'''(x) + … (1)
f(x − h) = f(x) − h·f'(x) + h²/2·f''(x) − h³/6·f'''(x) + … (2)

Разность вперёд. Из (1): f'(x) = (f(x+h) − f(x)) / h − h/2·f''(x) − …. Отбрасываем хвост и получаем f'(x) ≈ f(x+1) − f(x) при h = 1. Ошибка пропорциональна h (первый порядок точности). Ядро: [−1, 1]. Минус: у ядра нет центра, результат «сдвинут» на полпикселя.

Центральная разность. Вычтем (2) из (1): члены с h² сокращаются!

f(x+h) − f(x−h) = 2h·f'(x) + h³/3·f'''(x) + …
⇒ f'(x) ≈ (f(x+1) − f(x−1)) / 2, ошибка ~ h² ядро: ½·[−1, 0, 1]

Центральная разность точнее (второй порядок) и симметрична относительно центра. Именно её используют в Собеле.

Вторая производная. Сложим (1) и (2): нечётные члены сокращаются.

f(x+h) + f(x−h) = 2f(x) + h²·f''(x) + …
⇒ f''(x) ≈ f(x+1) − 2f(x) + f(x−1) ядро: [1, −2, 1]

Пример на ступеньке

f(x)20202020100100100100

f(x+1) − 2f(x) + f(x−1)0080−8000

Первая производная даёт пик на границе, вторая — смену знака (переход через ноль, zero crossing) ровно между пикселями 3 и 4. Два способа найти границу: искать максимум |f'| (Собель, Canny) или нули f'' (Лапласиан).

Лапласиан — сумма вторых производных по x и по y: ∇²f = f_xx + f_yy. Складываем ядра [1, −2, 1] по горизонтали и вертикали: [[0, 1, 0], [1, −4, 1], [0, 1, 0]]. В OpenCV: cv2.Laplacian(gray, cv2.CV_64F). Не зависит от направления границы, но ещё сильнее усиливает шум, поэтому на практике чаще используют Собеля и Canny.

3. Производная и шум: почему сначала блюр

Производная реагирует на любое изменение, в том числе на шум. Ровный пол с шумом камеры 50 52 49 51 50 53 48 даёт разности 2 −3 2 −1 3 −5: десятки маленьких «границ» на пустом месте. Если настоящая граница слабая, она утонет в шуме.

Решение — сначала сгладить, потом дифференцировать. И тут работает красивое свойство свёртки — она ассоциативна:

d/dx (G ∗ I) = (dG/dx) ∗ I

Сгладить картинку гауссом, а потом взять производную — то же самое, что один раз свернуть картинку с производной гаусса. Значит, можно сразу сделать одно ядро, которое и сглаживает, и дифференцирует. Это и есть идея Собеля.

4. Оператор Собеля

Вывод ядра

Чтобы найти вертикальные границы, нужна производная по x. Собель делает две вещи сразу:

  • по x берёт центральную разность [−1, 0, 1];
  • по y (поперёк направления производной) сглаживает ядром [1, 2, 1] — это маленький гаусс из урока 3 (биномиальные коэффициенты).

2D-ядро — внешнее произведение столбца сглаживания на строку производной (та же разделимость, что у гаусса):

⎡1⎤ ⎡−1 0 1⎤
Kx = ⎢2⎥ · [−1 0 1] = ⎢−2 0 2⎥
⎣1⎦ ⎣−1 0 1⎦

⎡−1 −2 −1⎤
Ky = Kxᵀ = ⎢ 0 0 0⎥
⎣ 1 2 1⎦

Как читать Kx: «правый столбец минус левый столбец, средняя строка с весом 2». Сумма весов равна 0, поэтому на однородной области (без перепада) результат 0.

Направления осей в OpenCV. Ось x идёт вправо, ось y — вниз. Gx > 0, когда справа светлее, чем слева. Gy > 0, когда снизу светлее, чем сверху. Для «правильной» производной ядро нужно делить на 8 (сумма модулей положительных весов 4, расстояние между столбцами 2), но для поиска границ масштаб неважен, и OpenCV не делит.

Ловушка: тип данных

Gx на границе «светлое → тёмное» отрицательный. Если считать в uint8, отрицательные значения обрежутся в 0, и половина границ пропадёт. Правильно: считать в CV_64F (или CV_16S), потом взять модуль.

gx = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)    # dx=1, dy=0: производная по x
gy = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)    # dx=0, dy=1: производная по y
show = cv2.convertScaleAbs(gx)                      # |gx|, приведено к uint8 для показа

Шарр (Scharr) — вариант Собеля с ядром [3, 10, 3] вместо [1, 2, 1]. Точнее определяет направление для ядра 3×3. В OpenCV: cv2.Scharr(gray, cv2.CV_64F, 1, 0) или cv2.Sobel(..., ksize=-1).

5. Градиент: модуль и направление

Градиент — вектор из двух производных: ∇I = (Gx, Gy). Он указывает направление, в котором яркость растёт быстрее всего, а его длина показывает, насколько резко. Граница проходит перпендикулярно градиенту.
|G| = √(Gx² + Gy²) модуль (сила границы), L2
|G| ≈ |Gx| + |Gy| быстрое приближение, L1
θ = atan2(Gy, Gx) направление градиента

atan2, а не atan(Gy/Gx): он учитывает знаки обеих компонент (различает все четыре четверти) и не ломается при Gx = 0.

6. Алгоритм Canny

Модуль Собеля — это ещё не границы, а «карта силы перепадов»: линии толстые, есть слабый шум, ясного ответа «граница / не граница» нет. Джон Кэнни (1986) сформулировал три требования к хорошему детектору:

  1. Хорошее обнаружение: находить настоящие границы и не находить ложных.
  2. Хорошая локализация: найденная граница должна лежать ровно там, где настоящая.
  3. Один отклик: одна граница — одна линия толщиной 1 пиксель.

Алгоритм состоит из пяти шагов, каждый отвечает за одно из требований.

Шаг 1. Сглаживание

Гауссов блюр (обычно 5×5, σ ≈ 1,4) убирает шум, иначе он даст ложные границы (требование 1). Встроенный cv2.Canny блюр не делает, его вызывают отдельно.

Шаг 2. Градиент

Собель: Gx, Gy, модуль |G| и угол θ для каждого пикселя (раздел 5).

Шаг 3. Подавление немаксимумов (Non-Maximum Suppression, NMS)

Граница в |G| выглядит как «хребет» шириной несколько пикселей. Нам нужна вершина хребта (требования 2 и 3). Идея: пиксель остаётся, только если он не меньше двух соседей вдоль направления градиента, то есть поперёк границы. Иначе он обнуляется.

Направление квантуют до четырёх вариантов (угол берут по модулю 180°, потому что «вправо» и «влево» для границы одно и то же):

Угол θКвантС какими соседями сравниватьГраница
[0°, 22,5°) или [157,5°, 180°)0°слева и справавертикальная
[22,5°, 67,5°)45°справа-снизу и слева-сверхудиагональ /
[67,5°, 112,5°)90°сверху и снизугоризонтальная

Пример: модули в окне [[10, 40, 15], [20, 60, 25], [5, 70, 12]], θ центра = 90°. Сравниваем центр 60 с верхним (40) и нижним (70) соседом. 70 > 60 — центр не максимум, обнуляем. Если бы θ = 0°, сравнивали бы с 20 и 25 — центр остался бы.

Шаг 4. Двойной порог

|G| ≥ high → сильная граница (точно граница)
low ≤ |G| < high → слабая граница (под вопросом)
|G| < low → не граница

Шаг 5. Гистерезис

Слабый пиксель остаётся, только если он связан (через цепочку соседей, 8-связность) с сильным. Логика: настоящая граница — непрерывная линия, и если часть линии точно граница, то её продолжение со слабым откликом тоже граница. Изолированные слабые пиксели — скорее всего шум. Так одним высоким порогом отсекается шум, а низким не рвутся линии.

Пример на одной строке: модули 10 60 120 70 30 80 40 150 20, low = 50, high = 100. Сильные: 120 и 150. Слабые: 60, 70, 80. Значения 60 и 70 касаются сильного 120 — остаются. 80 окружён «не границами» (30 и 40) — выбрасывается. Итог: 60, 120, 70 и 150.

Попробуйте пороги

Шаги 1–3 (блюр, Собель, NMS) заранее посчитаны в Python, а двойной порог и гистерезис выполняются прямо в браузере. В режиме «сильные / слабые»: белые — сильные, зелёные — слабые, которые выжили, красные — слабые, выброшенные гистерезисом.

В коде и параметры

  • Соотношение порогов: Кэнни рекомендовал high : low от 2:1 до 3:1.
  • Много лишних границ — поднимите high (меньше «семян») или усильте блюр.
  • Линии рвутся — опустите low (больше пикселей может продолжить линию).
  • Автоподбор (эвристика): взять медиану яркости m и поставить low ≈ 0,67·m, high ≈ 1,33·m.

7. Морфология

После порога, маски по цвету или Canny получается бинарная картинка. В ней почти всегда есть мусор: одиночные точки, дырки от бликов, разрывы линий. Морфологические операции чистят такие маски, меняя форму белых областей.

Структурный элемент (SE) — маленькая бинарная фигура с центром: квадрат 3×3, крест, эллипс. Он играет роль ядра, но вместо умножения и сложения используются логические операции (или min/max). Создаётся через cv2.getStructuringElement(cv2.MORPH_RECT | MORPH_CROSS | MORPH_ELLIPSE, (k, k)).

Эрозия и дилатация

Будем считать белые пиксели множеством A, а структурный элемент B, сдвинутый в точку z, обозначим Bz.

Эрозия: A ⊖ B = { z : B_z целиком лежит внутри A }
Дилатация: A ⊕ B = { z : B_z пересекается с A хотя бы в одной точке }

Простыми словами: при эрозии пиксель остаётся белым, только если все пиксели под SE белые (логическое И). При дилатации пиксель становится белым, если хотя бы один пиксель под SE белый (логическое ИЛИ). Для ЧБ-картинок это то же самое, что минимум и максимум по окну — та же схема, что медианный фильтр из урока 3, только берём не 5-е из 9, а 1-е или 9-е.

  • Эрозия «съедает» по краю: объекты худеют на радиус SE, мелкие точки и тонкие линии исчезают, слипшиеся объекты разделяются.
  • Дилатация «наращивает»: объекты толстеют, дырки и разрывы заполняются, близкие объекты сливаются.

Двойственность: эрозия белого — это дилатация чёрного. (A ⊖ B)ᶜ = Aᶜ ⊕ B̂, где ᶜ — дополнение (инверсия), B̂ — отражённый SE.

Открытие и закрытие

Открытие: A ∘ B = (A ⊖ B) ⊕ B сначала эрозия, потом дилатация
Закрытие: A • B = (A ⊕ B) ⊖ B сначала дилатация, потом эрозия
  • Открытие убирает мелкие белые объекты (меньше SE), а крупные возвращает почти к исходному размеру: эрозия их уменьшила, дилатация вырастила обратно. Точки, которые эрозия стёрла полностью, дилатации «не из чего» восстанавливать.
  • Закрытие заполняет маленькие чёрные дырки и разрывы внутри и между объектами, не раздувая объекты: дилатация закрыла дырку, эрозия вернула внешний размер.
  • Обе операции идемпотентны: повторное открытие ничего не меняет. Порядок важен: открытие и закрытие дают разные результаты.

Ещё три операции

Градиент: (A ⊕ B) − (A ⊖ B) контур объекта
Top-hat: A − (A ∘ B) то, что убрало открытие (мелкие светлые детали)
Black-hat: (A • B) − A то, что добавило закрытие (мелкие тёмные дырки)
K = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
er = cv2.erode(mask, K, iterations=1)
di = cv2.dilate(mask, K, iterations=1)
op = cv2.morphologyEx(mask, cv2.MORPH_OPEN, K)      # MORPH_CLOSE, MORPH_GRADIENT, MORPH_TOPHAT, MORPH_BLACKHAT

11. Типичные ошибки и шпаргалка

  • Собель в uint8: пропадают границы «светлое → тёмное».
  • Canny без блюра: много ложных границ (cv2.Canny сам не размывает).
  • Перепутаны dx и dy: Sobel(img, ddepth, 1, 0) — производная по x, то есть вертикальные границы.
  • atan вместо atan2: неправильные направления и деление на ноль.
  • Морфология на белом фоне с чёрным объектом: операции работают с белыми пикселями, сначала инвертируйте маску.
  • Открытие и закрытие перепутаны: открытие убирает точки, закрытие заделывает дырки.
  • Объект у края кадра: при закрытии он может «прилипнуть» к краю, потому что за краем при эрозии OpenCV считает пиксели белыми.

"""Собель с нуля: строим ядра, считаем Gx, Gy, модуль и направление градиента."""
from pathlib import Path
import cv2
import numpy as np
import matplotlib.pyplot as plt


def conv2d(img, kernel):
    """Свёртка из урока 3 (как cv2.filter2D: без переворота ядра, рамка-отражение)."""
    k = kernel.shape[0]; r = k // 2
    padded = np.pad(img.astype(np.float64), r, mode="reflect")
    H, W = img.shape
    out = np.zeros((H, W))
    for i in range(k):
        for j in range(k):
            out += kernel[i, j] * padded[i:i + H, j:j + W]
    return out


smooth = np.array([1, 2, 1])        # сглаживание (биномиальное, «маленький гаусс»)
deriv = np.array([-1, 0, 1])        # центральная разность
Kx = np.outer(smooth, deriv)        # сглаживаем по y, дифференцируем по x
Ky = np.outer(deriv, smooth)        # дифференцируем по y, сглаживаем по x
print("Kx =\n", Kx, "\nKy =\n", Ky)

patch = np.array([[10, 10, 90], [10, 10, 90], [10, 10, 90]])
print("Вертикальная граница: Gx =", (patch * Kx).sum(), " Gy =", (patch * Ky).sum())

gray = cv2.imread(str(Path(__file__).parent / "images" / "shapes.png"), cv2.IMREAD_GRAYSCALE)
assert gray is not None, "Запустите 00_make_images.py"
gx, gy = conv2d(gray, Kx), conv2d(gray, Ky)
print("Совпадает с cv2.Sobel:",
      np.allclose(gx, cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)),
      np.allclose(gy, cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)))

mag = np.hypot(gx, gy)                                  # sqrt(gx^2 + gy^2)
ang = np.degrees(np.arctan2(gy, gx)) % 360              # направление градиента, градусы

# Направление как цвет (H = угол), яркость = модуль: видно, куда «смотрит» каждая граница
hsv = np.zeros((*gray.shape, 3), np.uint8)
hsv[..., 0] = (ang / 2).astype(np.uint8)
hsv[..., 1] = 255
hsv[..., 2] = np.clip(mag / mag.max() * 255 * 2, 0, 255).astype(np.uint8)

items = [("исходная", gray, "gray"), ("Gx (красный +, синий −)", gx, "bwr"), ("Gy (вниз +, вверх −)", gy, "bwr"),
         ("|G| = sqrt(Gx² + Gy²)", mag, "gray"), ("направление (цвет) и |G| (яркость)", cv2.cvtColor(hsv, cv2.COLOR_HSV2RGB), None)]

04_canny_from_scratch.py — Canny по шагам с нуля и сравнение с cv2.Canny
"""Canny по шагам с нуля: блюр -> Собель -> подавление немаксимумов -> двойной порог -> гистерезис."""
from pathlib import Path
import cv2
import numpy as np
import matplotlib.pyplot as plt

LOW, HIGH = 50, 120          # пороги для модуля градиента (L2)

gray = cv2.imread(str(Path(__file__).parent / "images" / "cat.jpg"), cv2.IMREAD_GRAYSCALE)
assert gray is not None, "Нет images/cat.jpg"

# 1. Сглаживание
blur = cv2.GaussianBlur(gray, (5, 5), 1.4)

# 2. Градиент Собеля: модуль и направление
gx = cv2.Sobel(blur, cv2.CV_64F, 1, 0, ksize=3)
gy = cv2.Sobel(blur, cv2.CV_64F, 0, 1, ksize=3)
mag = np.hypot(gx, gy)
ang = np.degrees(np.arctan2(gy, gx)) % 180             # 0..180: направление «туда-обратно» одинаково


# 3. Подавление немаксимумов (NMS): оставить пиксель, только если он не меньше
#    двух соседей ВДОЛЬ направления градиента (поперёк границы)
def nms(mag, ang):
    H, W = mag.shape
    m = np.pad(mag, 1)                                    # рамка нулями
    out = np.zeros_like(mag)
    q = np.zeros((H, W), int)                              # квантуем угол в 4 направления
    q[(ang >= 22.5) & (ang < 67.5)] = 45
    q[(ang >= 67.5) & (ang < 112.5)] = 90
    q[(ang >= 112.5) & (ang < 157.5)] = 135
    # смещения соседей (dy, dx) для каждого направления; ось y направлена вниз
    offs = {0: (0, 1), 45: (1, 1), 90: (1, 0), 135: (1, -1)}
    c = m[1:-1, 1:-1]
    for d, (dy, dx) in offs.items():
        n1 = m[1 + dy:H + 1 + dy, 1 + dx:W + 1 + dx]       # сосед «по направлению»
        n2 = m[1 - dy:H + 1 - dy, 1 - dx:W + 1 - dx]       # сосед «против направления»
        keep = (q == d) & (c >= n1) & (c >= n2)
        out[keep] = c[keep]
    return out


thin = nms(mag, ang)

# 4. Двойной порог
strong = thin >= HIGH
weak = (thin >= LOW) & ~strong

# 5. Гистерезис: слабый пиксель остаётся, если связан (8 соседей) с сильным.
#    Размечаем связные области из сильных+слабых и оставляем те, где есть сильный пиксель.
n, labels = cv2.connectedComponents((strong | weak).astype(np.uint8), connectivity=8)
good = np.unique(labels[strong])
edges = np.isin(labels, good[good > 0]).astype(np.uint8) * 255

ref = cv2.Canny(blur, LOW, HIGH, L2gradient=True)
agree = np.mean((edges > 0) == (ref > 0)) * 100
print(f"Совпадение с cv2.Canny: {agree:.2f}% пикселей; границ у нас {np.count_nonzero(edges)}, у OpenCV {np.count_nonzero(ref)}")

vis = np.zeros((*gray.shape, 3), np.uint8)
vis[strong] = (255, 255, 255); vis[weak] = (255, 140, 0)
steps = [("1. блюр 5×5", blur, "gray"), ("2. |G| Собеля", mag, "gray"), ("3. после NMS (тонкие линии)", thin, "gray"),
         ("4. сильные (белые) и слабые (оранж.)", vis, None), ("5. после гистерезиса", edges, "gray"),
         ("cv2.Canny для сравнения", ref, "gray")]
fig, ax = plt.subplots(2, 3, figsize=(15, 14))
for a, (t, im, cm) in zip(ax.ravel(), steps):
    a.imshow(im, cmap=cm, vmax=None if cm is None else (np.percentile(im, 99.5) if t.startswith(("2", "3")) else None))
    a.set_title(t); a.axis("off")
plt.tight_layout()
plt.show()

06_morphology_basics.py — Эрозия, дилатация, открытие, закрытие, градиент на матрице 9×9
"""Эрозия, дилатация, открытие, закрытие и градиент на маленькой матрице и на картинке."""
import cv2
import numpy as np

# Объекты отстоят от края минимум на 2 пикселя: так рамка OpenCV не влияет на результат
A = np.zeros((9, 9), np.uint8)
A[2:5, 2:5] = 1          # квадрат 3×3
A[4, 6] = 1              # одиночная точка-«мусор»
A[6, 2:7] = 1            # линия толщиной 1
A[6, 4] = 0              # с разрывом в 1 пиксель
K = np.ones((3, 3), np.uint8)                               # структурный элемент 3×3
cross = cv2.getStructuringElement(cv2.MORPH_CROSS, (3, 3))

ops = {
    "эрозия": cv2.erode(A, K),
    "дилатация": cv2.dilate(A, K),
    "открытие (эрозия -> дилатация)": cv2.morphologyEx(A, cv2.MORPH_OPEN, K),
    "закрытие (дилатация -> эрозия)": cv2.morphologyEx(A, cv2.MORPH_CLOSE, K),
    "градиент (дилатация - эрозия)": cv2.morphologyEx(A, cv2.MORPH_GRADIENT, K),
    "дилатация крестом": cv2.dilate(A, cross),
}
print("A =\n", A)

def erode(img, k=3):
    p = np.pad(img, k // 2, mode="constant", constant_values=1)   # снаружи «1», как в OpenCV
    return np.min(np.lib.stride_tricks.sliding_window_view(p, (k, k)), axis=(-2, -1))

def dilate(img, k=3):
    p = np.pad(img, k // 2, mode="constant", constant_values=0)
    return np.max(np.lib.stride_tricks.sliding_window_view(p, (k, k)), axis=(-2, -1))

from pathlib import Path

assert img is not None, "Запустите 00_make_images.py"

mask = cv2.bitwise_or(cv2.inRange(hsv, np.array([0, 120, 70]), np.array([10, 255, 255])),
                      cv2.inRange(hsv, np.array([170, 120, 70]), np.array([179, 255, 255])))

K = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
opened = cv2.morphologyEx(mask, cv2.MORPH_OPEN, K)                  # убрать мелкие точки
closed = cv2.morphologyEx(opened, cv2.MORPH_CLOSE, K, iterations=3)  # заделать дырки (блики)
outline = cv2.morphologyEx(closed, cv2.MORPH_GRADIENT, K)          # контур объекта


def blobs(m):
    return cv2.connectedComponents(m)[0] - 1


items = [("фото с шумом", cv2.cvtColor(img, cv2.COLOR_BGR2RGB)), (f"маска: {blobs(mask)} пятен", mask),
         (f"открытие: {blobs(opened)} пятен", opened), (f"+ закрытие: {blobs(closed)} пятен", closed),
         ("морфологический градиент", outline)]
fig, ax = plt.subplots(1, 5, figsize=(22, 7))
for a, (t, im) in zip(ax, items):
    a.imshow(im, cmap="gray" if im.ndim == 2 else None); a.set_title(t); a.axis("off")
plt.tight_layout()
plt.show()

    print(t)            # сколько пятен осталось после каждого шага
