# Компьютерное зрение (OpenCV), ML и VLA для соревновательной робототехники

Образовательный курс и интерактивные конспекты лекций по классическому компьютерному зрению (OpenCV), нейросетям, VLM/VLA и их интеграции на робототехническом железе.

---

## 🚀 Деплой через GitHub Pages

Чтобы запустить сайт в открытом доступе через GitHub Pages:

1. Откройте репозиторий на GitHub: [kak0yt0-che1/OpenCV](https://github.com/kak0yt0-che1/OpenCV)
2. Перейдите во вкладку **Settings** (Настройки репозитория).
3. В левом боковом меню выберите пункт **Pages** (в разделе *Code and automation*).
4. В блоке **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`
   - **Branch**: выберите ветку `main`, папку `/ (root)`
   - Нажмите кнопку **Save**.
5. Подождите 1–2 минуты, пока выполнится автоматический GitHub Actions workflow.
6. Ваш сайт будет опубликован по адресу:
   **`https://kak0yt0-che1.github.io/OpenCV/`**

## 📚 Содержание курса

- **Модуль 1. Классическое зрение (10 часов)**
  - Урок 1: Изображение как матрица. Цветовые пространства (RGB vs HSV)
  - Урок 2: Бинаризация и фильтрация. Маски и пороговые фильтры (Thresholding)
  - Уроки 3–10: Свёртки, фильтры Собеля/Canny, контуры, калибровка камеры, ArUco/AprilTags, Optical Flow, проектный час
- **Модуль 2. Введение в ML и свёрточные сети (10 часов)**
- **Модуль 3. Детекция объектов и Edge AI (10 часов)**
- **Модуль 4. VLM: трансформеры и мультимодальность (10 часов)**
- **Модуль 5. Архитектура управления и финальный проект (10 часов)**
